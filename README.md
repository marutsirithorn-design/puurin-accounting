# ระบบบัญชีร้าน (Google Apps Script + Google Sheet)

## ไฟล์ในโปรเจกต์
| ไฟล์ | หน้าที่ |
|---|---|
| `Code.gs` | หลังบ้าน (API, ล็อกอิน, คำนวณสรุป, อ่าน/เขียนชีต) |
| `Index.html` | โครงหน้าเว็บ |
| `Stylesheet.html` | ธีมสี + ฟอนต์ Prompt |
| `JavaScript.html` | การทำงานฝั่งหน้าเว็บ |
| `appsscript.json` | ตั้งค่าโปรเจกต์ (เขตเวลา, การ deploy) |

## วิธีติดตั้ง (ทำครั้งเดียว)
1. เปิด Google Sheet → เมนู **ส่วนขยาย (Extensions) → Apps Script**
2. ลบโค้ดเดิมในไฟล์ `Code.gs` แล้ววางเนื้อหาจาก `Code.gs` ของโปรเจกต์นี้
3. กด **+ → HTML** สร้างไฟล์ 3 ไฟล์ ชื่อ `Index`, `Stylesheet`, `JavaScript` (ไม่ต้องพิมพ์ .html) แล้ววางเนื้อหาตามไฟล์
4. (แนะนำ) ⚙️ Project Settings → ติ๊ก *Show "appsscript.json"* → วางเนื้อหาจาก `appsscript.json`
5. เลือกฟังก์ชัน **`setup`** ที่แถบด้านบน → กด **Run** → อนุญาตสิทธิ์ (Review permissions → Allow)
   - ระบบจะสร้างชีต `DB_Users`, `DB_Bills`, `DB_Expenses`, `DB_Categories`, `DB_Employees`, `DB_Payroll`, `DB_Settings`
   - ชีตเดิม (พ.ย, ธ.ค, เงินเดือนพนักงาน ฯลฯ) **ไม่ถูกแก้ไข**
6. **Deploy → New deployment** → เลือก type: **Web app**
   - Execute as: **Me**
   - Who has access: **Anyone** (พนักงานไม่ต้องมีบัญชี Google — ระบบใช้ชื่อผู้ใช้/รหัสผ่านของตัวเอง)
7. คัดลอก URL ของ Web app ไปเปิดในมือถือ/คอมพิวเตอร์ (บนมือถือ กด “เพิ่มไปยังหน้าจอโฮม” ได้)

**ผู้ใช้เริ่มต้น:** `admin` / `admin1234` → เข้าแล้วกดที่ชื่อผู้ใช้ เพื่อ **เปลี่ยนรหัสผ่านทันที**

> อัปเดตจากเวอร์ชันก่อน: วางโค้ดใหม่ทับแล้ว deploy ได้เลย ระบบจะสร้างชีต `DB_Audit` ให้เองตอนเปิดหน้าเว็บครั้งแรก
>
> แก้โค้ดภายหลัง: Deploy → Manage deployments → ✏️ → Version: **New version** → Deploy (URL เดิมยังใช้ได้)

## การใช้งาน
**บันทึกรายวัน** (ทุกคน)
- เพิ่มบิลรายโต๊ะ: เลขโต๊ะ, ค่าอาหารและเครื่องดื่ม, ส่วนลด, ค่าบัตรคอนเสิร์ต, เงินสด/โอน
- **สรุปรายวัน** (หลังเพิ่มบิลครบ): แยกค่าอาหาร / ค่าเครื่องดื่ม (กรอกค่าอาหาร ระบบเติมค่าเครื่องดื่มให้), สรุปส่วนลด, ยอดรวม, กำไร/ขาดทุน, ยอดยกมาจากเมื่อวาน (อัตโนมัติ หรือกรอกเอง), ยอดสุทธิ — เพิ่ม/แก้ไข/ลบได้ (พนักงานแก้ไขต้องใช้รหัสผู้ดูแล) เก็บในชีต `DB_DaySummary`
- เพิ่มรายจ่ายตามหมวด
- ดูสรุปยอดขาย, เงินในลิ้นชัก (เงินทอนตั้งต้น, รับ/จ่ายเงินสด, เงินที่ควรมี) และยอดสุทธิสะสมของเดือน
- ปุ่ม “บันทึก + เพิ่มต่อ” ช่วยกรอกหลายบิลติดกันได้เร็ว

**สรุปรายเดือน** (ผู้ดูแลระบบ) — ตารางรายรับรายวันดึงจากสรุปรายวัน (อาหาร หลังหักส่วนลด, เครื่องดื่ม, บัตรคอนเสิร์ต, ยอดขายสุทธิ, ค่าใช้จ่ายรายวัน, กำไรรายวัน) วันที่ยังไม่สรุปจะขึ้น “รอสรุปรายวัน”, ปุ่ม **ส่งออก Excel** (ไฟล์ .xlsx 3 ชีต: รายวัน / สรุปเดือน / รายจ่ายตามหมวด), รายรับ/รายจ่าย/คงเหลือ, กราฟรายวัน, กำไรอาหาร–เครื่องดื่ม (%), รายจ่ายแต่ละหมวด, งบสรุปรายเดือน, ตารางรายวันแบบชีตเดิม, พิมพ์รายงาน

**หลังบ้าน** (ผู้ดูแลระบบ)
- **หัวข้อรายรับ** — เพิ่มหัวข้อรายรับเองได้ (เช่น ค่าห้อง VIP, ค่าอื่น ๆ) แสดงเป็นช่องในบิล, สรุปรายวัน, ตารางรายเดือน (คอลัมน์ใหม่), สรุปยอดรายเดือน, Excel และประวัติการแก้ไข — หัวข้อที่มีบิลใช้แล้วลบไม่ได้ ระบบจะ “ปิดใช้งาน” แทน (ชีต `DB_IncomeTypes`)
- **หมวดรายจ่าย** — เพิ่ม/แก้/ปิด, กำหนด “กลุ่มในรายงาน” และ “ประเภทต้นทุน” (อาหาร/เครื่องดื่ม/ทั่วไป) ที่ใช้คำนวณกำไร
- **เงินเดือนพนักงาน**
  - **รอบจ่ายค่าแรง** (เพิ่ม/ดู/แก้ไข/ลบ) แยก 2 ประเภท:
    - **รายวัน** — ค่าแรง × จำนวนวัน = รวมเงิน, รายการเพิ่ม, รายการหัก (เบิก), ได้รับสุทธิ, ธนาคาร, เลขบัญชี, จ่ายโดย
    - **รายเดือน** — เงินเดือน, รายการเพิ่ม, หักเบิกล่วงหน้า, หักรายจ่ายอื่น, ได้รับสุทธิ, ธนาคาร, เลขบัญชี, จ่ายโดย
    - เปิดหน้าแล้วเห็นตารางทันที: กดปุ่ม **ค่าแรงรายวัน / เงินเดือนรายเดือน** ระบบดึงพนักงานกลุ่มนั้น + ค่าแรง/เงินเดือน + บัญชี + ยอดเบิกในงวดมาแสดง กรอกแล้วกด “บันทึกรอบจ่าย” — รอบที่บันทึกแล้วอยู่ใน “ประวัติรอบจ่าย” ด้านล่าง, ส่งออก Excel / พิมพ์ A4 แนวนอน, กด “ยืนยันจ่ายแล้ว” เพื่อนับยอดสุทธิเป็นรายจ่ายในวันที่จ่าย (ชีต `DB_PayRuns`, `DB_PayRunItems`)
  - **เบิกล่วงหน้า / จ่ายรายครั้ง** — นับเป็นรายจ่ายในวันที่เบิก และถูกหักในรอบจ่ายของงวดนั้น
- **รายชื่อพนักงาน** — ชื่อ, ชื่อเล่น, ตำแหน่ง, ค่าแรงรายวัน/รายเดือน, ธนาคาร, เลขบัญชี, สถานะ
- **ผู้ใช้และสิทธิ์** — ผู้ดูแลระบบ: ใช้ได้ทุกอย่าง แก้ไขได้ทุกวัน / พนักงาน: เพิ่มรายการของวันนี้ได้เลย แต่การ **แก้ไข/ลบรายการที่บันทึกแล้ว** หรือ **เพิ่มรายการย้อนหลัง** ต้องให้ผู้ดูแลระบบใส่รหัสผ่านอนุมัติ พร้อมระบุเหตุผล
- **ประวัติการแก้ไข** — ทุกการเพิ่ม/แก้ไข/ลบ ถูกบันทึกในชีต `DB_Audit` (ใครทำ, ข้อมูลเดิม → ใหม่, ใครอนุมัติ, เหตุผล) ใช้ตรวจสอบการทุจริตย้อนหลัง
- **ตั้งค่าร้าน** — ชื่อร้าน, เงินทอนตั้งต้นค่าเริ่มต้น (5,000)
- **เงินในลิ้นชัก** (หน้าบันทึกรายวัน, เฉพาะผู้ดูแลระบบ) — กำหนดเงินทอนตั้งต้นเฉพาะวัน และบันทึกเงินสดที่นับได้จริง ระบบแสดงเงินเกิน/ขาด และเก็บประวัติในชีต `DB_DailyCash` + `DB_Audit`

## หมายเหตุ
- ไม่ควรแก้หัวคอลัมน์หรือคอลัมน์ `id` ในชีต `DB_` ด้วยมือ
- รหัสผ่านเก็บแบบเข้ารหัส (SHA-256 + salt) — ลืมรหัส ให้ผู้ดูแลระบบตั้งรหัสใหม่ในเมนู “ผู้ใช้และสิทธิ์”
- ล็อกอินค้างไว้ได้ 6 ชั่วโมงนับจากการใช้งานล่าสุด, ใส่รหัสผิด 5 ครั้งจะถูกพักการเข้าสู่ระบบ 5 นาที
